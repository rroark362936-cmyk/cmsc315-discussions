# Unit 5 Discussion: Search Algorithms

## Overview

This assignment compared linear search and binary search algorithms implemented in Python.

## Learning Objectives Completed

- Implemented linear search examining elements sequentially ($O(n)$ time complexity).
- Implemented binary search dividing the sorted search window in half iteratively ($O(\log n)$ time complexity).
- Compared algorithm performance across small and large datasets.
- Analyzed algorithm efficiency and edge cases, including empty lists and single-element datasets.

## Implementation Summary

- **Linear Search:** Successfully iterated through lists from start to finish to find target values or return -1.
- **Binary Search:** Utilized `low`, `high`, and `mid` pointers on sorted data to rapidly narrow down search spaces.
- **Testing:** Validated both algorithms using small arrays, a large dataset of 1,000 elements, and edge cases like empty inputs.

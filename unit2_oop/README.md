While working on this assignment, I learned how stacks and queues actually operate in Python and how they store data differently.
The main challenge I ran into was figuring out what happens when you try to pull something out of an empty stack or queue, which kept breaking my code.
I finally fixed it by adding simple if-statements to check if it was empty first before trying to remove anything.
Through this, I really started to understand the practical difference between LIFO and FIFO.
Stacks use Last-In, First-Out, kind of like an undo button where the most recent thing you did is the first thing that gets reversed.
Queues, on the other hand, use First-In, First-Out, which is just like standing in a normal line at a store or waiting for a printer where whoever gets there first gets helped first.
Overall, it was pretty cool to see how these two basic data structures show up and solve problems in everyday software.
